# Лекция → Карточки

Веб-приложение: загружаешь файл лекции (или вставляешь текст) — GigaChat
раскладывает материал на карточки для повторения.

## Как запустить локально

1. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```

2. Получи ключ GigaChat:
   - Зайди на https://developers.sber.ru/studio
   - Создай проект → GigaChat API → "Получить ключ" (Authorization key)
   - Выбери тариф **Freemium** (бесплатный, для физлиц)

3. Скопируй `.env.example` в `.env` и вставь свой ключ:
   ```
   cp .env.example .env
   ```
   Открой `.env` и впиши `GIGACHAT_AUTH_KEY`.

   ⚠️ **Никогда не вставляй ключ прямо в код и не отправляй `.env` в чат/git.**
   Файл `.env` уже стоит добавить в `.gitignore`, если будешь заливать
   проект на GitHub.

4. Запусти сервер:
   ```
   uvicorn app:app --reload
   ```

5. Открой в браузере: http://127.0.0.1:8000

## Про SSL-сертификаты GigaChat

GigaChat использует сертификаты российского удостоверяющего центра.
Пока они не установлены в систему, `requests` будет ругаться на SSL —
поэтому в коде сейчас стоит `VERIFY_SSL = False` (в `app.py`).
Для локальной разработки и теста это нормально. Если решишь идти
в продакшен — стоит скачать цепочку сертификатов НУЦ Минцифры
(https://gu-st.ru/content/Other/doc/russian_trusted_root_ca_pem.crt)
и указать путь к ней вместо `False`.

## Деплой на Render (бесплатно)

1. Залей проект на GitHub (не забудь `.gitignore` с `.env` внутри).
2. На render.com → New → Web Service → подключи репозиторий.
3. Build command: `pip install -r requirements.txt`
4. Start command: `uvicorn app:app --host 0.0.0.0 --port $PORT`
5. В разделе Environment добавь переменные `GIGACHAT_AUTH_KEY` и
   `GIGACHAT_SCOPE` (те же значения, что в твоём `.env`).
